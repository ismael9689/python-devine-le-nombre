# Guess the Number

A small Python game where the player has to guess a random number between 1 and 100.

## Features

- Random secret number
- Hints: "higher" / "lower" (`Plus haut` / `Plus bas` in the game)
- Counts your attempts

## Run the project

```bash
python3 devine_le_nombre.py
```
